# Meu Remédio — Política de Privacidade

Página pública da política de privacidade do app **Meu Remédio: Alarme de Remédio** (Android e iOS), em português e
inglês, servida pelo GitHub Pages: <https://heinzbidel.github.io/meu-remedio-politica/>

As lojas exigem uma URL pública e estável. Este repositório existe só para isso. Tem de dizer o mesmo que a tela
«Privacidade e termos» do app (`app/assets/textos/pt_BR/ui.json`, chaves `privacidade.*`): quem mudar um muda o outro.
Publicada em 22/11/2026, por ordem do Heinz («Sim, como no Siloé»).
